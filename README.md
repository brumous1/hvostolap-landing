# Хвостолап — Лендинг ветеринарной клиники

Демо-лендинг для ветеринарной клиники «Хвостолап» (Москва).

**Live:** https://brumous1.github.io/hvostolap-landing/

## Что внутри

- Фиксированная навигация с телефоном
- Hero-блок с ключевыми показателями клиники
- Блок услуг с ценами (6 карточек)
- Команда врачей (4 специалиста)
- Блок преимуществ
- Форма записи на приём + контакты
- Адаптивная вёрстка под мобильные устройства

## Технологии

Чистый HTML + CSS, нет фреймворков и зависимостей.

## Использование

Открыть `index.html` в браузере — больше ничего не нужно.
